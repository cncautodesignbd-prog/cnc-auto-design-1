# CNC Auto Design - Centralized Admin System

## সমস্যা (Problem)
আপনার ওয়েবসাইটে যে সমস্যাটা ছিল:
- যখন কোনো ইউজার একাউন্টের জন্য আবেদন করে, সেই রিকোয়েস্ট ঐ কম্পিউটারের localStorage এ সংরক্ষিত হয়
- অন্য কোনো ডিভাইস থেকে এডমিন প্যানেল খুললে সেই রিকোয়েস্ট দেখায় না
- ফলে: একই কম্পিউটার থেকে এডমিন প্যানেল অ্যাক্সেস করতে হতো

## সমাধান (Solution)
আমরা একটি **Node.js সার্ভার** তৈরি করেছি যা সব রিকোয়েস্ট এবং ইউজার ডেটা কেন্দ্রীয়ভাবে সংরক্ষণ করবে। এখন যেকোনো ডিভাইস থেকে এডমিন প্যানেল অ্যাক্সেস করা যাবে।

## ইনস্টলেশন স্টেপস (Installation Steps)

### ১. Node.js ইনস্টল করুন
যদি আপনার কম্পিউটারে Node.js না থাকে, তাহলে [Node.js ওয়েবসাইট](https://nodejs.org/) থেকে ডাউনলোড করে ইনস্টল করুন।

### ২. সার্ভার সেটআপ করুন
```bash
# টার্মিনাল ওপেন করুন (Command Prompt/PowerShell)
cd "c:\Users\Hi Maruf\Desktop\web"

# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# সার্ভার চালু করুন
npm start
```

### ৩. সার্ভার চালু হলে আপনি দেখতে পাবেন:
```
🚀 Server running on http://localhost:3000
📁 Data directory: c:\Users\Hi Maruf\Desktop\web\data
🌐 Admin panel: http://localhost:3000/login/admin.html
🏠 Main site: http://localhost:3000/login/index.html
```

## কিভাবে ব্যবহার করবেন (How to Use)

### ওয়েবসাইট অ্যাক্সেস:
- **মেইন সাইট**: http://localhost:3000/login/index.html
- **এডমিন প্যানেল**: http://localhost:3000/login/admin.html

### কাজ করার ধাপা:
1. **সার্ভার চালু করুন**: `npm start`
2. **ইউজার একাউন্ট তৈরি করুন**: যেকোনো ডিভাইস থেকে main site এ গিয়ে একাউন্ট তৈরি করুন
3. **এডমিন প্যানেল থেকে অনুমোদন দিন**: যেকোনো ডিভাইস থেকে admin panel এ গিয়ে রিকোয়েস্ট অনুমোদন দিন

## ফিচার (Features)

### ✅ কেন্দ্রীয় ডেটা সংরক্ষণ:
- সব রিকোয়েস্ট সার্ভারে সংরক্ষিত হয়
- সব এক্টিভ ইউজার সার্ভারে সংরক্ষিত হয়
- সেটিংস সার্ভারে সংরক্ষিত হয়

### ✅ মাল্টি-ডিভাইস সাপোর্ট:
- একই সময়ে একাধিক ডিভাইস থেকে এডমিন প্যানেল অ্যাক্সেস করা যায়
- রিয়েল-টাইম আপডেট

### ✅ ফলব্যাক সাপোর্ট:
- যদি সার্ভার বন্ধ থাকে, localStorage এ কাজ করবে
- কোনো ডেটা হারাবে না

### ✅ অটোমেটিক ব্যাকআপ:
- ডেটা JSON ফাইলে সংরক্ষিত হয়
- সার্ভার রিস্টার্ট করলেও ডেটা থাকবে

## ডেটা স্টোরেজ (Data Storage)
সব ডেটা `data` ফোল্ডারে JSON ফাইল আকারে সংরক্ষিত হয়:
- `data/requests.json` - সব পেন্ডিং রিকোয়েস্ট
- `data/activeUsers.json` - সব অনুমোদিত ইউজার
- `data/settings.json` - এডমিন সেটিংস

## ট্রাবলশুটিং (Troubleshooting)

### সার্ভার চালু হচ্ছে না:
```bash
# পোর্ট 3000 ফ্রি কিনুন
netstat -ano | findstr :3000

# অন্য পোর্টে সার্ভার চালু করুন
PORT=8080 npm start
```

### ফায়ারওয়াল ব্লক হচ্ছে:
উইন্ডোজ ফায়ারওয়াল সেটিংস এ গিয়ে Node.js এবং নেটওয়ার্ক অ্যাক্সেস দিন।

### ডেটা দেখাচ্ছে না:
- ব্রাউজার কনসোল চেক করুন (F12)
- সার্ভার চলছে কিনা দেখুন: http://localhost:3000/api/health
